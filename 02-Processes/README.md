# العمليات الرئيسية (Core Processes)

قائمة بالعمليات الأساسية في المشروع.

كل عملية يجب أن تتحول لاحقاً إلى SOP مفصل في مجلد `03-SOPs`.

## أمثلة على عمليات:
- اكتساب العملاء (Lead Generation)
- تحويل العميل (Sales)
- تقديم الخدمة / المنتج
- خدمة ما بعد البيع
- المحاسبة والمالية
- التوظيف والتدريب

أضف عملياتك هنا كملفات منفصلة.
