# نظام العمل الذاتي (E-Myth Business System)

مستودع قالب لبناء **نظام عمل يعمل بنفسه** مستوحى من كتاب *The E-Myth Revisited* لمايكل جيربر.

الهدف: تحويل مشروعك من "أنت تعمل فيه" إلى "مشروع يعمل بنفسه" من خلال أنظمة وعمليات موثقة.

## الفكرة الأساسية
- اعمل **على** المشروع لا **فيه**
- ابنِ أنظمة (Systems) و إجراءات تشغيل قياسية (SOPs)
- وازن بين الأدوار الثلاثة: رائد الأعمال + المدير + الفني
- اجعل المشروع قابلاً للتكرار (مثل الامتياز التجاري)

## هيكل المستودع

```
e-myth-business-system/
├── 00-Vision/              # الرؤية والاستراتيجية
├── 01-Roles/               # الأدوار والمسؤوليات
├── 02-Processes/           # العمليات الرئيسية
├── 03-SOPs/                # إجراءات التشغيل القياسية
├── 04-Metrics/             # المقاييس والأرقام
├── 05-Org-Chart/           # الهيكل التنظيمي
├── 06-Tools/               # الأدوات والبرمجيات المستخدمة
├── 07-Onboarding/          # تدريب الموظفين الجدد
├── templates/              # قوالب جاهزة
└── README.md
```

## كيف تستخدم هذا المستودع؟
1. انسخه (Fork أو Clone) إلى حسابك.
2. ابدأ بملء مجلد **00-Vision** أولاً.
3. ثم حدد الأدوار في **01-Roles**.
4. وثق العمليات في **02-Processes** وحوّلها إلى SOPs في **03-SOPs**.
5. أضف المقاييس في **04-Metrics**.
6. استمر جزءاً جزءاً حتى يصبح نظامك كاملاً.
